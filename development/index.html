IntentDrift Analyzer

Cross-lingual LLM Evaluation Framework

  • Proposed and implemented a framework for analyzing latent intent drift in multilingual LLM pipelines, demonstrating that translation preserves surface meaning while distorting intent-level reasoning.
  • Designed a structured pipeline: English → Hindi/German → Back-translation for measuring drift through intent consistency, semantic divergence, and reasoning variation.
  • Built an interactive visualization system for sample-level analysis revealing systematic intent shifts such as: Polarization → Action and confidence degradation after translation.
