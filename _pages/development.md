<h5 style="margin-bottom:5px;">
IntentDrift Analyzer
</h5>

<p style="color:gray; margin-top:0;">
Cross-lingual LLM Evaluation Framework
</p>

<ul>

<li>
Proposed and implemented a framework for analyzing
<strong>latent intent drift</strong> in multilingual
LLM pipelines, demonstrating that translation
preserves surface meaning while distorting
intent-level reasoning.
</li>

<li>
Designed a structured pipeline:
English → Hindi/German → Back-translation
for measuring drift through
<strong>intent consistency</strong>,
<strong>semantic divergence</strong>,
and <strong>reasoning variation</strong>.
</li>

<li>
Built an interactive visualization system for
sample-level analysis revealing systematic
intent shifts such as:
<strong>Polarization → Action</strong>
and confidence degradation after translation.
</li>

</ul>

StrokeSense.ai
</h5>

<p style="color:gray; margin-top:0;">
Handwriting Style Modeling
</p>

<ul>

<li>
Built a training-free handwriting style transfer
system that extracts structural characteristics
including <strong>stroke patterns</strong>,
<strong>spacing</strong>,
and <strong>slant</strong>.
</li>

<li>
Applied extracted features to standard fonts
to mimic personalized writing styles.
</li>

<li>
Designed a lightweight feature-engineering
pipeline avoiding deep learning requirements,
allowing efficient personalization under
low-data and no-GPU settings.
</li>

</ul>
